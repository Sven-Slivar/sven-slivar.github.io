gostly

A playtest toolkit for indie game developers. Testers play your build and press F8 when something's off. Gostly records where they went and what broke, and shows you what to fix first.

Not released yet. Everything on this page is built and runs with automated tests on my machine. Hosting and a public release come next. The screens show the real dashboard running on sample data from a made-up game.

Why I'm building it

My master's thesis ran on gameplay logs: 28 players and 255 sessions of Parry Simulator. Logging everything that happens in a game, where players go, where they die and what breaks, turned out to be the most useful part of the study.

Small teams test with friends, Discord communities and game jam players, but they get feedback like "the boss felt unfair" with no way to see what happened. Gostly turns the logging into a tool any small team can drop into its game, so the next playtest is easier.

Gost is Croatian for "guest": testers are guests in your game, and they leave ghosts behind.

What it does

Testers only play and press F8. Everything else happens on the developer's side.

01
Ghost replays

The SDK records each tester's position a few times a second, and the dashboard replays many sessions at once on a map of the level. Deaths, stuck spots and reports sit on the same timeline, with heatmaps and named zones on top. No video needed.

02
Bug reports from inside the game

F8 opens a small window in the game. The report arrives with a screenshot, recent logs, the device, the position in the level and a link to that moment in the replay. Crashes file themselves, grouped by cause, and a report can be sent to GitHub as an issue.

03
What to fix first

After a playtest round, Overview leads with plain findings: a new crash, a spot where several testers got stuck, where runs end, and what changed since the last build. Every finding plays the exact moments behind it.

04
Not only for games about moving

Each project picks a game profile when it's created. Action games get the map replay; card and turn-based games get run flow and pick rates per card; simulators get ghost lines, one line per tester for a value like coins over time.

05
Patch notes from git

A command-line tool reads the commits since the last release, groups them and marks the reports they fix, then writes notes for Steam, Discord, itch.io and plain text. gostly check can fail a CI build when deaths or crashes per session get clearly worse.

How it's built

Six parts in one repository, each with its own tests.

Unity SDK
C# · 144 tests
Batched, compressed telemetry off the main thread, an offline outbox, the F8 report window and a consent prompt. Editor tools draw ghosts in the Scene view, list reports and capture level maps at build time.
API
Java 21, Spring Boot · 197 tests
PostgreSQL and S3 storage. Rate-limited ingest with safe retries, replay decoding, heatmaps, findings, crash grouping, team members, GitHub issues and a Discord digest.
Dashboard and site
React, TypeScript · 146 tests
Replays and heatmaps drawn on canvas without a UI or chart library, dark and light themes, phone layouts, and a public landing page and docs.
Command-line tool
Node, TypeScript · 36 tests
Patch notes from git, report lists in the terminal, build comparison and a CI check.
Godot and web game SDKs
GDScript, JavaScript · 42 tests · early
The same recording, reports and consent for Godot 4 (an addon with an editor dock) and for browser games, sending to the same API.
